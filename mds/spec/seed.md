## GOAL

한 화면을 좌(P1)/우(P2) **2뷰포트로 분할**하고, 각 플레이어가 자기 비행기를 **3인칭 추격 시점**으로 조종해 **기관총·유도미사일·플레어**로 상대를 격추하는 **2인 로컬 분할화면 아케이드 공중전(도그파이트) WebGL 게임**을 만든다. 비행은 아케이드(자동 수평 안정·스톨 없음) 모델이며, 고정 설계맵(바다 바닥 + 섬 + 산 + 다리)을 전투 엄폐·회피에 활용한다. 지형/수면 충돌은 폭발 즉사, 체력 0이면 사망이며, 한 명이 죽으면 결과창에서 **단판 재대결**한다.

## ACCEPTANCE_CRITERIA

- **분할화면**: 한 캔버스가 좌(P1)/우(P2) 2뷰포트로 나뉘고 각 뷰가 해당 플레이어 기체를 3인칭 추격 카메라로 렌더한다
- **2P 동시 조작**: 좌/우 키 바인딩이 충돌 없이 독립 동작(피치·롤·부스터·감속·기관총·미사일·플레어)
- **아케이드 비행**: 자동 수평 안정·스톨 없음, 기본속도 일정 + 부스터로 가속·감속키로 감속
- **월드 경계**: 경계 근처 진입 시 "이탈 경고" HUD 표시 → 더 나가면 기체가 서서히 강제 선회로 복귀(보이지 않는 벽). 경계로 인한 사망은 없음
- **기관총**: 키 홀드 시 연사, 탄창 100발, 소진 시 재장전 3초(재장전 중 발사 불가), 1발 명중당 체력 -1, 탄에 사거리/수명 제한
- **유도미사일**: 총 2발, 명중 시 체력 -50, 발사 전 락온 2초 필요, 정면 락 콘(~15°) 안에 상대가 있고 최소사거리(~150m)~최대사거리(~1200m) 범위일 때만 발사 가능, 발사 후 상대를 선회율 제한 내에서 유도 추적, 수명 후 자폭/소멸
- **플레어**: 총 3발, 전개 시 일정 시간/반경 내의 유도미사일이 빗나가게(디코이) 함, 전개에 쿨다운 적용
- **지형 충돌 즉사**: 기체가 지형(섬·산·다리) 또는 수면(y=0)에 충돌하면 폭발과 함께 즉사
- **체력 0 사망**: 각 기체 체력 100에서 시작, 0 이하가 되면 사망
- **색 선택 중복 불가**: 시작화면에서 6색 중 각자 선택하되 두 플레이어가 같은 색을 고를 수 없다
- **결과창/재대결**: 한 명이 죽으면 승패 결과창 표시 → 재대결 버튼으로 단판 재시작
- **고정 설계맵**: 바다 바닥 + 섬 여러 개 + 산(고산 1~2 포함) + 다리 모양 지형이 전투 엄폐·회피에 활용 가능하게 배치
- **HUD**: 각 분할 뷰에 체력·기관총 탄약/재장전·미사일 잔량·플레어 잔량·락온 상태·이탈 경고 표시
- **사운드**: 엔진음 + 효과음(기관총·미사일발사·락온경고·폭발) + 음악
- 핵심 순수 로직(flight/input/terrain/gun/missile/flare/combat)에 대한 Vitest 단위 테스트가 모두 통과
