# ✈️ 2P 분할화면 도그파이트 (WebGL)

한 화면을 **좌(P1)/우(P2) 2뷰포트로 분할**하고, 각자 비행기를 **3인칭 추격 시점**으로 조종해 **기관총·유도미사일·플레어**로 상대를 격추하는 **2인 로컬 아케이드 공중전** 게임. 바다·섬·산·다리로 이루어진 고정 설계맵 위에서 단판 대결한다.

---

## 🖥️ 실행

```bash
npm install      # three, vite, vitest
npm run dev      # 개발 서버 → http://localhost:5173
npm run build    # 프로덕션 번들
npm test         # Vitest 단위 테스트 전체
```

## 🎮 조작법

| | P1 (왼쪽) | P2 (오른쪽) |
|---|---|---|
| 피치 ↑/↓ | `W` / `S` | `↑` / `↓` |
| 롤(좌/우 선회) | `A` / `D` | `←` / `→` |
| 부스터 | `Left Shift` | `Right Shift` |
| 감속(코브라) | `Q` | `/` |
| 기관총 | `E` | `.` |
| 미사일 | `R` | `,` |
| 플레어 | `F` | `Right Ctrl` · `M` |

공용: `` ` ``(백쿼트) 음소거.

**팁**: 감속 키를 오래 누르면 엔진오프처럼 거의 멈춰 **코브라 기동**(기수 급상승)이 가능하다.

## ⚔️ 규칙

- 체력 **100**, 0이면 사망. **기관총 명중 −1**, **유도미사일 −50**.
- **유도미사일 2발** — 정면 락 콘(~15°)·사거리(150~2000m)에서 **락온 2초** 후 발사, 선회율 제한 유도. **60초당 1발 재장전**.
- **플레어 3발** — 유도미사일을 빗나가게(디코이). **180초당 1발 재장전**.
- **지형/수면 충돌 = 폭발 즉사.** 월드 경계는 강제 선회(이탈 경고).
- 한 명 사망 → 결과창 → **재대결**(단판).
